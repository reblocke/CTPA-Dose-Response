# Data Dictionary

This dictionary documents the restricted inputs, key source variables, derived variables, model variables, and generated outputs for the CTPA dose-response analysis repository.

The companion machine-readable file is [`data_dictionary.csv`](data_dictionary.csv). Rows marked `needs_review` are inferred from Stata scripts and the unpublished manuscript draft; verify against the restricted source data before using them for data sharing or formal reproducibility claims.

## Restricted Inputs

| File | Role | Public? | Notes |
| --- | --- | --- | --- |
| `data/private/final_noempi.dta` | Primary restricted Stata source dataset for preprocessing and the older combined workflow. | No | Patient-level clinical imaging/EHR-derived data. The name indicates direct EMPI removal but does not make the file public. |
| `data/private/cleaned_noempi.dta` | Cleaned restricted dataset expected by the main age-metric and body-size analysis scripts. | No | Can be generated locally by `Data_preprocess.do` or supplied as a compatible restricted file. |
| `data/private/ACCT EMPI BMI Weight Height.csv` | Supplemental restricted body-size/age file merged during preprocessing. | No | Contains linkage fields such as account/person identifiers and must not be committed. |

## Key Source Variables

| Variable | Meaning | Notes |
| --- | --- | --- |
| `age` | Age at CTPA/index encounter. | Used in tables, splines, and stratified survival models. |
| `male` | Sex indicator, with labels `0 = Female`, `1 = Male` in the scripts. | Used for sex-specific PA diameter normalization and adjustment. |
| `bmi`, `height`, `weight`, `bsa` | Body-size variables. | `bsa` is derived locally from height/weight; units should be verified in the restricted source. |
| `mpad` | Main pulmonary artery diameter. | Primary imaging predictor, in millimeters. |
| `ascendingaorta` | Ascending aorta diameter measured at the same CT level. | Used as an imaging covariate and denominator. |
| `mpaaa` | Pulmonary artery to ascending aorta ratio. | Derived as PA diameter divided by ascending aorta diameter. |
| `death` | Vital status failure indicator. | Used in `stset` survival analyses. |
| `lastfollowupday`, `lastfollowupyear` | Follow-up time. | `lastfollowupyear` is the survival-time scale used by the Stata workflows. |

## Comorbidity and Adjustment Variables

Observed model covariates include `obesity_calc`, `hypertension`, `diabetes1`, `diabetes2`, `diabetes3`, `chf`, `pulmdisease`, `pulmonarycircdisorders`, `peripheralvascdisorders`, and `renalfailure`.

Most diagnosis variables are inferred from the existing analysis scripts rather than from a public codebook. The CSV dictionary marks these rows `needs_review` because ICD definitions, lookback windows, and source-system details are not public in this repository.

## Derived Analysis Variables

| Variable | Meaning | Source |
| --- | --- | --- |
| `enlargedpa` | Conventional sex-specific enlarged PA diameter indicator. | Derived in Stata from `mpad` and `male`; usual threshold is >27 mm for women and >29 mm for men. |
| `enlargedratio` | Increased PA:AA ratio indicator. | Derived from `mpaaa > 0.90`. |
| `enlargedaa` | Enlarged ascending aorta indicator. | Threshold should be verified in the Stata script. |
| `age_decade` | Decade-scale age category. | Used in table and stratified model output. |
| `age_bi_decade` | Broad age category: younger, middle, older. | Used for age-stratified survival figures. |
| `mpad_tertile`, `mpaaa_tertile`, `aa_tertile` | Data-derived tertiles for PA, PA:AA, and AA. | Quantile cut points are data-dependent. |
| `mpad_cat`, `mpaaa_cat`, `aa_cat` | Category variables for imaging measures. | Exact bins need review before reuse. |
| `pa_confusion_matrix`, `pa_aa_confusion_matrix` | Joint classifications of imaging abnormality. | Value labels should be verified in Stata. |
| `mpad_hat_z`, `aa_hat_z`, `mpaaa_hat_z` | Age/sex model-based residual or z-score style variables. | Exact reference models and denominators need review. |
| `z_mpad_tertile`, `z_aa_tertile`, `z_mpaaa_tertile` | Tertiles of normalized metrics. | Used in age/sex normalization analyses. |
| `rc*` | Restricted cubic spline basis variables. | Temporary variables generated by `mkspline2` for Cox models. |

## Generated Outputs

The refactored scripts write generated materials under `outputs/stata/<date>/`, including:

- logs and copied do-files;
- cleaned local `.dta` files;
- mismatch/QC CSV files;
- `table1_mc` Excel table exports;
- `outreg2` regression tables;
- Kaplan-Meier, hazard, spline, quantile-regression, and body-size plots.

These outputs are ignored by git. Historical rendered notebook HTML/PDF exports are preserved in the GitHub release `legacy-rendered-artifacts-2026-06-04` for provenance and reading convenience.

## Review Flags

Before formal data sharing or reproduction:

- verify exact source definitions for diagnosis comorbidities;
- confirm height/weight units and body surface area formula;
- verify PA/AA measurement conventions against the original measurement protocol;
- review all value labels for categorical imaging variables;
- confirm whether any private QC exports contain identifiers before sharing.
